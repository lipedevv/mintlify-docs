> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

対応対象は Paper 1.21.8 と Java 21 以降です。VS Code は Nexora Connect のライブ状態または GUI プレビューを使う場合のみ必要です。

言語セレクターを使用して、ローカライズされたドキュメントを切り替えられます。API 識別子は、すべての言語で正確な JavaScript 形式を維持します。
