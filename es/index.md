> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Objetivo compatible: Paper 1.21.8 y Java 21 o superior. Nexora Connect necesita VS Code solo para estado en vivo o vista previa de GUI.

Usa el selector de idioma para cambiar entre las versiones localizadas de la documentación. Los identificadores de la API conservan su forma JavaScript exacta en todos los idiomas.
