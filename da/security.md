description: "Safe Mode starter med HostAccess.NONE. Behold 127.0.0.1 og autentificering, brug minimale capabilities og giv ikke native.java/native.paper til ukendt kode."
icon: shield-check

Native Mode must be enabled in both `config.yml` and `workspace.json`. Treat a native workspace exactly like a Java plugin and review all of its source before enabling it.
