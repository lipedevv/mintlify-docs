> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Understøttet mål: Paper 1.21.8 og Java 21 eller nyere. VS Code kræves kun til live-status eller GUI-preview med Nexora Connect.

Brug sprogvælgeren til at skifte mellem lokaliseret dokumentation. API-identifikatorer bevarer deres nøjagtige JavaScript-form på alle sprog.
