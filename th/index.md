> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

เป้าหมายที่รองรับคือ Paper 1.21.8 และ Java 21 ขึ้นไป ใช้ VS Code เฉพาะเมื่อต้องการสถานะสดหรือดูตัวอย่าง GUI ผ่าน Nexora Connect

ใช้ตัวเลือกภาษาเพื่อสลับระหว่างเอกสารที่แปลแล้ว ตัวระบุ API จะคงรูปแบบ JavaScript ที่ถูกต้องเหมือนเดิมในทุกภาษา
