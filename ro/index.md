> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Țintă suportată: Paper 1.21.8 și Java 21 sau mai nou. VS Code este necesar doar pentru starea live sau previzualizarea GUI din Nexora Connect.

Folosiți selectorul de limbă pentru a comuta între versiunile localizate ale documentației. Identificatorii API își păstrează forma JavaScript exactă în toate limbile.
