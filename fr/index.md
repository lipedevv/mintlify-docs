> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Cible prise en charge : Paper 1.21.8 et Java 21 ou plus récent. VS Code n’est requis que pour l’état en direct et l’aperçu GUI de Nexora Connect.

Utilisez le sélecteur de langue pour changer de documentation localisée. Les identifiants de l’API conservent leur forme JavaScript exacte dans toutes les langues.
