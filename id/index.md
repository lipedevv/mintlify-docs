> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Target yang didukung: Paper 1.21.8 dan Java 21 atau lebih baru. VS Code hanya diperlukan untuk status langsung atau pratinjau GUI Nexora Connect.

Gunakan pemilih bahasa untuk beralih di antara dokumentasi yang dilokalkan. Pengenal API tetap menggunakan bentuk JavaScript yang sama persis di setiap bahasa.
