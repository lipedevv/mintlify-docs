> Saving `workspace.json`, `.js`, `.mjs` or local `.json` files is enough. There is no Deploy Workspace command.

Bij een afgewezen wijziging los je de eerste workspace-waarschuwing op zonder revisies te wissen. Stop het oude proces bij een bezette poort, start nooit twee Paper-instanties voor dezelfde wereld en gebruik nogui op Windows.
