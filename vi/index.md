> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Mục tiêu được hỗ trợ: Paper 1.21.8 và Java 21 trở lên. VS Code chỉ cần khi dùng trạng thái trực tiếp hoặc xem trước GUI của Nexora Connect.

Dùng bộ chọn ngôn ngữ để chuyển giữa các bản tài liệu đã bản địa hóa. Các định danh API luôn giữ nguyên dạng JavaScript chính xác trong mọi ngôn ngữ.
