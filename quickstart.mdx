This guide walks you through your first authenticated request to Nexora. You will create a workspace and list its resources using real request and response examples. By the end, you will have a working integration pattern you can reuse for any endpoint.

## Prerequisites

- A Nexora account. If you do not have one yet, sign up at [app.nexora.io](https://app.nexora.io).
- An API key from the Nexora Dashboard. Go to **Settings \> API Keys**, then click **Generate Key**.
- An HTTP client such as `curl`, or a scripting environment with `fetch` or `requests`.

<Steps>
  <Step title="Install an HTTP client or use curl">
    You can follow this guide with `curl`, Node.js, or Python. Choose whichever fits your stack.

    <CodeGroup>

    ```bash
    # curl is available on most systems
    curl --version
    ```

    ```bash
    # Node.js (for fetch examples)
    node --version
    ```

    ```bash
    # Python (for requests examples)
    python --version
    ```

    </CodeGroup>
  </Step>
  <Step title="Get your API key from the Dashboard">
    Log in to [app.nexora.io](https://app.nexora.io) and navigate to **Settings \> API Keys**. Click **Generate Key**, copy the token, and store it securely. Nexora expects this token in the `Authorization: Bearer <token>` header on every request.

    <Tip>
      Treat your API key like a password. Do not commit it to version control. Use environment variables in production.
    </Tip>
  </Step>
  <Step title="Create your first workspace">
    Send a `POST` request to `/workspaces` with a name for your workspace.

    <CodeGroup>

    ```bash curl
    curl -X POST https://api.nexora.io/v1/workspaces \
      -H "Authorization: Bearer $NEXORA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "Acme Production"}'
    ```

    ```js JavaScript
    const response = await fetch("https://api.nexora.io/v1/workspaces", {
      method: "POST",
      headers: {
        "Authorization": "Bearer " + process.env.NEXORA_API_KEY,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ name: "Acme Production" }),
    });
    const data = await response.json();
    console.log(data);
    ```

    ```python Python
    import requests, os
    
    resp = requests.post(
      "https://api.nexora.io/v1/workspaces",
      headers={
        "Authorization": f"Bearer {os.environ['NEXORA_API_KEY']}",
        "Content-Type": "application/json",
      },
      json={"name": "Acme Production"},
    )
    print(resp.json())
    ```

    </CodeGroup>

    You should receive a response like this:

    ```json
    {
      "id": "ws_2vPqN9mK3Lx8",
      "name": "Acme Production",
      "created_at": "2024-01-15T09:23:11Z",
      "updated_at": "2024-01-15T09:23:11Z"
    }
    ```

    Save the `id` value. You will use it to list resources in the next step.
  </Step>
  <Step title="List your resources">
    Now query the workspace to see its resources. New workspaces start empty, so the list will be blank until you add resources later.

    ```bash
    curl -G https://api.nexora.io/v1/workspaces/ws_2vPqN9mK3Lx8/resources \
      -H "Authorization: Bearer $NEXORA_API_KEY" \
      -d "limit=10"
    ```

    Expected response:

    ```json
    {
      "data": [],
      "next_cursor": null
    }
    ```

    The `data` array holds resources such as databases, queues, and storage. The `next_cursor` field supports pagination when there are more results. See the [Pagination guide](/guides/pagination) for details.
  </Step>
