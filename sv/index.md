> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Mål som stöds: Paper 1.21.8 och Java 21 eller senare. VS Code behövs endast för live-status eller GUI-förhandsvisning med Nexora Connect.

Använd språkvalet för att växla mellan lokaliserad dokumentation. API-identifierare behåller sin exakta JavaScript-form på alla språk.
