## What you can build

- **Team infrastructure provisioning**: Create workspaces, attach databases, queues, and storage, and manage member access from your own tools.
- **Event-driven automation**: Subscribe to webhook events like `resource.created` and `workspace.member.added` to trigger workflows in your stack.
- **Internal dashboards and CLI tools**: Use cursor-based pagination and consistent error formats to build reliable admin interfaces and scripts.

## Get started in three steps

<Steps>
  <Step title="Create your account">
    Sign up at [app.nexora.io](https://app.nexora.io) to access the Nexora Dashboard.
  </Step>
  <Step title="Get your API key">
    Generate a Bearer token from the Dashboard under **Settings \> API Keys**.
  </Step>
  <Step title="Make your first call">
    Use your key to create a workspace via the REST API. See the [Quickstart](/quickstart) for a complete copy-pasteable example.
  </Step>
</Steps>
