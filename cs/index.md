> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Podporovaný cíl: Paper 1.21.8 a Java 21 nebo novější. VS Code je nutný pouze pro živý stav nebo náhled GUI v Nexora Connect.

Pomocí voliče jazyka přepínejte mezi lokalizovanými verzemi dokumentace. Identifikátory API si v každém jazyce zachovávají přesný tvar JavaScriptu.
