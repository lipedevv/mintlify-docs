description: "O Modo Seguro começa com HostAccess.NONE. Mantenha 127.0.0.1, autenticação ligada e capacidades mínimas; nunca conceda native.java ou native.paper a código não confiável."
icon: shield-check

Native Mode must be enabled in both `config.yml` and `workspace.json`. Treat a native workspace exactly like a Java plugin and review all of its source before enabling it.
