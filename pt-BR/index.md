> **Nexora 1.0.0** · Paper 1.21.8 · Java 21+ · JavaScript · automatic safe reload

Alvo suportado: Paper 1.21.8 e Java 21 ou superior. O VS Code só é necessário para status ao vivo e prévia de GUI pelo Nexora Connect.

Use o seletor de idioma para alternar entre as versões localizadas da documentação. Os identificadores da API mantêm a forma JavaScript exata em todos os idiomas.
